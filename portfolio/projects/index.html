SimContext — AI-Ready Engineering Context from Simulation Models

Engineering AI · FEM · ANSYS · Abaqus · LLM Workflows

SimContext is an engineering AI tool that transforms ANSYS and Abaqus simulation models into structured engineering knowledge and AI-ready context.

The system automatically parses FEM input files, extracts engineering metadata, identifies modelling risks, generates validation recommendations, and produces concise context summaries for LLMs, agents, and engineering RAG systems.

The project was motivated by a common engineering challenge: simulation models often contain valuable domain knowledge, but understanding an existing model can require manually reading thousands of lines of solver input.

MINT — Masonry in-situ testing and material identification

Funded by the Engineering and Physical Sciences Research Council (EPSRC).

The MINT project aims to estimate mechanical properties of existing masonry assets using Digital Image Correlation (DIC) techniques combined with the Virtual Fields Method (VFM). We apply non-contact optical measurements and inverse methods to extract stiffness and elastic parameters from standard in-situ tests, enabling improved condition assessment of heritage and historic masonry.

High-speed camera based operational modal analysis

Camera-based Operational Modal Analysis (OMA) and the pyOMA toolbox.

This work compares camera-based OMA with conventional experimental modal analysis using piezoelectric sensors. We developed a Python toolbox, pyOMA, implementing the Frequency Domain Decomposition (FDD) method. The methods were validated on a reference structure and tested on a custom setup with emphasis on how sensor mass affects identified modal properties.
